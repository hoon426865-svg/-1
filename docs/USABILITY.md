# 현장 입력과 화면 개선

## 일상 업무

- **생산:** 품목·LOT 생산을 주 입력으로 사용한다. 도번을 입력하여 품명·모델을 확인하고 실제 LOT와 양품·불량 수량을 기록한다. 간단 수량 기록은 품목·LOT 미연결 업무를 위한 별도 입력이다. 같은 생산량을 양쪽에 입력하지 않는다.
- **자재:** PR·SP·MO·PG 부품은 도번으로 입고한다. 품목의 기본 공급업체를 확인하고 이번 입고에 맞게 수정할 수 있다. 입고 후 품질에서 검사한다.
- **품질:** AS 조립품은 납품 대상을 직접 등록하고 출하검사 후 납품 완료를 기록한다. 부품은 입고·생산 LOT 검사에서 처리한다. AS의 납품 예정 수량이 자재 재고로 자동 생성되지 않는다.
- **반복 입력:** 입고·AS 등록의 계속 입력을 선택하면 다음 등록에 공통 품목·거래처 정보를 이어 쓸 수 있다. 다음 LOT·수량·메모는 다시 입력한다. 검사 결과나 합격 판정은 자동으로 채우지 않는다.
- **내역 찾기:** 현재 불러온 페이지에서 도번·LOT 등의 검색과 상태 필터를 사용한다. 필터 결과와 건수는 전체 DB 집계가 아니다. 다른 페이지는 이전·다음으로 이동한다.
- **근무 신청:** 오늘 날짜·하루만 신청 버튼과 입력 요약으로 날짜 범위를 확인한다. 기간 내 모든 날짜에 같은 시간이 적용되며 주말·공휴일도 포함된다.

상태는 색과 글자를 함께 표시하고, 수량·현재 품목·저장 버튼의 크기와 대비를 높였다. 홈에서 권한이 있는 자재·품질 업무로 바로 이동할 수 있다. 상세 도움말과 기존 간단 입력은 필요한 경우 펼쳐서 사용한다.

## 추가 품목 파일 등록

실제 회사 품목과 검사 기준은 공개 소스에 넣지 않는다. 전달받은 비공개 JSON 파일을 사용한다.

1. 업데이트 배포 후 기존 관리자 계정으로 온워크에 로그인한다.
2. 설정의 품목 파일 가져오기에서 추가 품목 JSON을 선택한다.
3. 도번·품명·모델과 추가/건너뛰기/오류 내역을 확인한다.
4. 추가 버튼으로 등록한다. 이미 있는 도번은 덮어쓰지 않고 건너뛴다. 사용 중지 품목도 자동 활성화하지 않는다.
5. AS는 품질 관리에서 해당 도번을 입력해 납품 대상을 등록한다.

신규 품목에 검사 기준이 제공되지 않았다면 비워 둔다. 실제 적용 도면·개정·샘플링 기준을 확인하여 설정 또는 검사 입력에서 기록해야 한다. 다른 조립품의 기준을 임의로 복사하지 않는다. 품목 등록은 재고나 실제 납품 기록 생성과 별개다.

## 검증과 배포

기존 계정·패스키·권한·DB 구조는 유지한다. 코드 업데이트는 기존 고정 주소에 Codespaces 배포 절차로 반영한다. 새로운 DB 마이그레이션은 없다. 실제 운영 품목 등록 여부는 파일 가져오기 결과로 확인한다.

검증에는 기존 Node/Worker 회귀 검사, 실제 합성 DB를 사용하는 브라우저 UI 검사, 반복 입력·중복 제출·초안 보존·검색 범위·품목 가져오기 검사가 포함된다. CI의 화면 검토 이미지는 격리된 합성 데이터만 사용하며, 실제 회사 자료나 사용자 인증 정보를 포함하지 않는다. 실제 휴대폰의 키보드·패스키·현장 작업 확인은 별도다.
