# 카테고리별 화면 구성 — 2026-11-03

기존의 긴 관리자·직원 화면을 메뉴별로 나눴습니다. PC는 왼쪽 고정 메뉴, 900px 이하 화면은 상단 메뉴 버튼을 사용합니다. 선택한 메뉴 하나만 표시하고 현재 위치를 강조합니다. 홈은 서버가 반환한 오늘의 기록과 기존 계산 함수로 현황을 표시합니다.

| 메뉴 | 관리자 | 직원 |
|---|---|---|
| 홈 | 오늘 출근·생산·야근 검토 현황, 주요 기능 바로가기 | 본인의 오늘 출퇴근·생산 현황, 주요 기능 바로가기 |
| 출퇴근 | 날짜별 직원 출퇴근과 상태 | 출근·퇴근 입력과 본인 기록 |
| 생산 관리 | 날짜별 직원 생산량, 작업 종류 추가·수정 | 생산량 입력과 본인 기록 |
| 근무 신청 | 조회·승인·반려·재검토·처리 이력 | 본인 신청·수정·재신청·처리 이력 |
| 직원 관리 | 직원 추가·정보 수정·재직 상태·기존 계정 복구 기능 | 제공하지 않음 |
| 통계·보고서 | 기존 직원별 월간·연간 내역과 이력 | 제공하지 않음 |
| 설정 | 현재 계정·권한·로그인 방식·시간 기준, 자료 새로고침·로그아웃 | 같은 기능, 본인 계정 정보만 표시 |

미구현 QR 화면, 출퇴근 정정 화면, 잔여 휴가·자동 차감·급여 계산 등은 추가하지 않았습니다. 출퇴근 시각, 생산 집계, 신청 중복·승인·기간 계산은 기존 규칙을 사용합니다.

## 입력과 이동

- 메뉴 이동 시 기존 화면 요소를 유지합니다. 신청 작성, 관리자 의견, 직원·작업 편집 내용이 유지됩니다.
- 앱의 새로고침 및 다른 폼 저장 후 재조회에도 미저장 입력을 복원합니다. 편집 시작 당시의 버전도 유지하므로 다른 사용자의 최신 변경을 덮어쓰지 않습니다.
- 브라우저 새로고침·닫기는 미저장 내용이 있을 때 브라우저의 이탈 확인을 요청합니다. 사용자가 이탈을 승인하면 미저장 내용은 사라집니다. 브라우저 정책에 따라 확인창 제공 여부가 달라질 수 있습니다.
- 로그아웃 시 미저장 내용 폐기 여부를 확인합니다. 인증 계정·권한이 바뀌면 이전 화면과 입력을 폐기합니다. 다른 탭에서 로그인 계정이 바뀐 뒤 재조회하는 경우도 포함합니다.
- 작성 내용, 비밀번호, 등록권은 localStorage/sessionStorage나 URL에 저장하지 않습니다. URL의 `#home`, `#attendance` 등에는 메뉴 이름만 남습니다. 새로고침·뒤로/앞으로 이동 시 허용된 메뉴를 복원합니다.
- 신청 처리 후 이미 열어 둔 보고서도 다시 조회합니다. 서버 실패를 성공이나 빈 집계로 표시하지 않습니다.

## 보존 범위

서버 변경은 `/navigation.js`, `/drafts.js` 정적 파일 제공에 한정됩니다. 서버의 인증·역할·본인 기록 필터·CSRF·Origin·버전 충돌 검사는 유지합니다. 패스키 검증·발급·계산 코드, 스키마·마이그레이션은 변경하지 않았습니다. 실제 계정·패스키·DB·업무 기록에 쓰기 작업을 수행하지 않았습니다.

관리자 패스키 복구는 사용자의 기존 로그인 성공 확인 후 중단된 상태입니다. 이번 작업에서도 등록권 발급·패스키 삭제·재등록·DB 초기화·실제 관리자 생성은 하지 않았습니다.

## Git 저장과 실제 배포의 구분

화면 변경과 검증 파일은 현재 브랜치 `feat/workers-passkey-free-preview`에서 별도 커밋으로 관리합니다. 기존 CPU 작업의 미커밋 변경 6개는 그대로 남기며 이번 화면 커밋에 섞지 않습니다. HANDOFF에는 이 문서로 연결하는 최신 안내만 별도로 저장합니다.

2026-11-03 고정 주소 `https://onwork-preview-20261007-01.hoon426865.workers.dev`를 읽기 전용으로 조회했습니다. `/api/setup`은 패스키 모드와 기존 주소를 반환했고, `/app.js`는 새 로컬 파일과 달랐으며 `/navigation.js`, `/drafts.js`는 404였습니다. **새 메뉴 화면은 아직 고정 주소에 반영되지 않았습니다.** 원격 배포·main 병합·DB 이전은 수행하지 않았습니다.

기존 무료 CPU 초과·계측 누락 문제는 별도 미완료 작업입니다. 정적 파일 허용 목록과 개발 의존성 잠금 파일이 바뀌어 배포 검증용 해시도 달라집니다. 이전 CPU 결과를 이 버전의 무료 운영 통과로 취급하지 않습니다.
