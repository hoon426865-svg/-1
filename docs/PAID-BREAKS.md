# 오전·오후 유급 휴게 반영

회사가 확인한 기준은 정상 출퇴근 08:30~17:30, 점심 12:30~13:30 무급, 오전 10:30~10:40 및 오후 15:30~15:40 휴게 유급입니다.

- 기본 실근무: 9시간 − 점심 60분 − 휴게 20분 = 7시간 40분.
- **급여 인정 기본시간**: 기본 실근무 + 기본시간대의 유급 휴게 = 8시간.
- 지각·조퇴 시 실제 집계 구간과 겹치는 휴게만 반영합니다. 매일 20분을 일괄 가산하지 않습니다. 예: 10:35~17:30은 오전 휴게 5분, 오후 휴게 10분을 포함해 인정 기본시간 5시간 55분입니다.
- 중복 구간은 합집합으로 한 번만 계산합니다. 자정 이후 또는 기본시간 밖의 휴게를 출근일 기본 급여 인정시간에 더하지 않습니다.
- 추가근무, 유급휴가, 임금·수당 및 최종 급여 계산은 별도입니다. 이번 인정 기본시간에는 자동 가산하지 않습니다.
- 퇴근 누락·잘못된 구간·기준 적용일 이전 기록은 인정 기본시간 미확정입니다. 합계에는 미확정 일수와 확인된 소계를 표시합니다.

관리자 보고서와 CSV에서 점심, 오전·오후 휴게, 기본 실근무, 급여 인정 기본시간을 구분합니다. 기존 `payrollMinutes`는 최종 급여시간 미확정 의미를 유지하며, `payrollBasicMinutes`가 출근 기록 기준 인정 기본시간입니다.

## 기준과 자료 보존

새 기준은 `attendance-2026-11-03-v2`, 적용일은 회사 확인일인 2026-11-03입니다. `migrations/0006_paid_break_policy.sql`은 정책 한 건만 추가합니다. 원본 시각·기존 정책·정정 이력·월별 확정본을 변경하지 않습니다. 이전 확정본에는 새 인정시간을 자동 채우지 않습니다. 필요한 경우 관리자가 재계산 미리보기를 검토한 뒤 사유를 남겨 재확정합니다.

배포 전 DB 백업과 사본 검증을 수행하고, 기존 근태 보고서 마이그레이션이 적용된 DB에 0006을 적용한 뒤 코드를 배포합니다. Node는 시작 시 같은 정책을 한 번 추가합니다. 정책 추가 후 이전 코드로 돌아가도 기존 정책과 확정본은 남습니다. DB 초기화나 테스트 자료 삭제는 이 변경에 포함하지 않습니다.

검증은 정상 8시간, 초 단위 지각, 휴게 중 출퇴근, 점심만 포함된 구간, 중복·자정 이후 근무, 미확정 합계, CSV, 기존 확정본 보존, 관리자 권한과 모바일 화면을 다룹니다.
