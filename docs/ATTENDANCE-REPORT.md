# 직원별 근태 집계 — 2026-11-03

관리자의 **통계·보고서**에서 연도·월·직원을 선택해 출근일수, 근무일수, 출퇴근 상세, 근무시간과 신청 승인 결과를 조회합니다. 기존 신청·승인·생산 내역은 같은 화면의 펼침 영역에 유지합니다. 직원 화면과 서버 API의 권한 구분은 그대로입니다.

## 출근과 시간 계산

- 한국 시간 기준 기본근무 08:30~17:30. 08:30 이전 도착은 기본집계 시작을 08:30으로 표시하고, 이후 도착은 실제 시각부터 계산합니다. 실제 출근·퇴근 시각은 함께 표시하며 변경하지 않습니다.
- 휴게 10:30~10:40, 점심 12:30~13:30, 휴게 15:30~15:40 중 출퇴근 구간과 겹치는 부분만 공제합니다. 정상 하루의 기록 기준 기본근무는 7시간 40분입니다.
- 초 단위 시각을 보존합니다. 화면에서 시간·분·필요시 초로 표시하고 CSV에는 초 단위 숫자도 제공합니다.
- 17:30 이후 실제 기록을 추가근무로 표시합니다. 승인된 추가근무 신청 시간과 실제 기록의 교집합을 별도 표시하고, 대기·반려·신청 없는 나머지 추가시간은 확인 대상으로 남깁니다. 승인을 했다는 이유만으로 근무시간을 생성하지 않습니다.
- 08:30 이전 도착 자체는 기본근무에 포함하지 않습니다. 실제 조기근무가 있었다면 기존 추가근무 신청·승인 절차로 해당 구간을 등록할 수 있습니다. 승인 구간과 실제 기록이 겹치는 조기근무만 추가근무 집계에 포함합니다. 조기 도착 원본과 미반영 시간은 상세·CSV에 남습니다.
- 기존 출퇴근 건별 야근 승인은 해당 기록의 17:30 이후 구간에만 적용합니다. 신청 승인과 겹쳐도 이중 계산하지 않습니다.
- 출근일수는 출근 기록이 있는 날짜 수입니다. 근무일수는 퇴근이 완료되고 집계시간이 있는 날짜 수입니다. 승인 부재 날짜 수는 유형별로 따로 표시하며 근무일수나 연차 차감량에 더하지 않습니다. 부분 시간 부재도 해당 유형의 날짜 1개로 표시합니다.
- 퇴근 누락·동일 근무일 중복·잘못된 시각·48시간 초과 구간은 시간 합계에서 제외하고 확인 필요로 표시합니다. 퇴근 시각을 17:30으로 자동 채우지 않습니다.
- 자정을 넘는 근무는 출근일에 귀속합니다. 월·연말 근무를 대조할 수 있도록 최대 다음 이틀의 승인 내역도 읽지만, 기존 월·연 신청 통계에는 조회 기간과 겹치는 신청만 포함합니다.

## 자료의 의미와 보존

새 집계는 `attendance-0830-v1` 기준으로 기존 기록을 읽어 계산하는 참고 자료입니다. 기존 출퇴근·승인 이력, 과거 저장·확정 자료, 계정, 패스키를 변경하지 않습니다. DB 마이그레이션은 없습니다. 조회 날짜가 과거인 경우에도 현재 보고서 기준으로 재계산한 값이라는 안내를 표시합니다.

근태 시간과 급여 인정 시간은 동일하다고 가정하지 않습니다. 휴게시간의 유급 여부, 임금·수당·세금, 법정 연장·야간·휴일수당 및 휴가 잔여량 계산은 이번 변경에 포함하지 않습니다. 근무일 달력이 없으므로 기록이 없는 날짜를 자동 결근 처리하지 않습니다.

## CSV

- **직원별 합계 CSV**: 조회 기간, 사번·이름·팀, 출근·근무·미확정·확인필요 일수, 기본·추가·승인대조·미확정 추가시간, 집계시간, 지각·조퇴, 승인 부재 날짜 수, 기준 버전.
- **일별 출퇴근 CSV**: 원본 출퇴근 및 기본집계 시작, 휴게·기본·추가시간, 조기 도착과 승인 여부, 상태·확인 사항, 관련 신청 및 처리자·처리 시각·의견, 기록 ID·버전.
- 내려받기마다 관리자 API로 다시 조회합니다. Workers의 모든 페이지를 동일 revision으로 모은 후 계산하며, 중간에 데이터가 바뀌면 부분 보고서를 내보내지 않습니다.
- UTF-8 BOM과 CSV 인용·줄바꿈 처리를 사용하고, 직원 이름·의견 등의 스프레드시트 수식 실행을 차단합니다. Excel에서 사번 앞자리 0을 표시하려면 ‘텍스트/CSV에서 가져오기’에서 사번 열 형식을 텍스트로 지정합니다.
- CSV에는 직원 정보가 있으므로 Git에 저장하지 않습니다. 내려받은 파일은 관리자 업무용으로 보관합니다.

## 구현과 검증

- `public/attendance-report.js`: Node/Workers에서 공통으로 사용하는 계산·CSV 함수.
- `public/attendance-view.js`: 관리자 근태 표와 일별 상세.
- 기존 관리자 보고 API를 확장하며 Node는 서버, Workers는 권한 검사 후 받은 전체 페이지를 브라우저에서 집계합니다. 보호된 데이터의 권한은 서버에서 검사합니다.
- 기존 신청 승인·반려·재검토 API와 불변 이력을 재사용합니다.
- `npm run verify`: 계산 경계·누락·중복·휴게·야근·월말·권한·페이지 조회 및 기존 기능 회귀 검사.
- `npm run test:ui`: 관리자 조회·CSV, 직원 접근 차단, 화면 이동과 입력 보존, 390px 모바일 화면 검사. 가상 DB만 사용합니다.

검증 결과: Node 61개, Workers 27개, UI 9개 검사를 통과했습니다. 실제 iPhone 패스키 및 운영 환경의 성능 검증은 이 검사 결과에 포함하지 않습니다. 코드 저장과 실제 사이트 배포는 별도 단계입니다.
