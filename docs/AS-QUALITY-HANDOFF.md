## 확정된 업무 흐름

- AS: 품질 권한으로 도번·납품처·LOT·수량을 직접 등록 → 출하검사 → 불합격 보류/재검사 → 합격 후 LOT 전체 실제 납품 완료 확인. 자재 입고가 필요 없고 재고·생산 실적을 중복 가산하지 않는다. 취소는 사유와 이력을 보존한다. 부분 납품은 지원하지 않으므로 납품 단위로 LOT를 구분한다.
- PR·SP·MO·PG: 도번으로 자재 입고 → 품질 검사 → 기존 출고 처리. 하이픈/밑줄/공백 생략과 대소문자를 허용한다. 품명·모델·공급업체를 표시하며 미등록·모호·사용 중지 번호와 다른 계열의 등록을 차단한다.
- 기존 AS 입고/생산 LOT는 입고·생산 LOT 검사에서 유지하며 같은 품목·LOT의 직접 등록을 막는다. AS 생산 실적은 유지하고 신규 승인 때 재고를 추가 생성하지 않는다.
- 기존 품목 JSON을 가져왔다면 재등록할 필요 없다. 도번으로 계열을 판단한다. 회사 품목·검사기준 JSON과 원본 자료는 공개 Git에 포함하지 않는다.
